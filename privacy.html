OpenClaw Host Recovery

Privacy policy

This policy covers the personal backup utility and its public information pages.

Google account and Drive data

The utility uses the authorized Google account identity to select the backup destination. It uses Drive’s per-file permission to store and retrieve backup archives and their metadata, such as file names and IDs, for backup and recovery.

Storage and retention

Archives are encrypted before upload and kept in the account owner’s Google Drive until the owner deletes them. The utility uses downloaded files for recovery and removes temporary copies after verification. The owner can revoke access in Google Account connections.

Use and sharing

Google provides authorization and file storage. The utility uses Google user data only for backup and recovery and does not sell it or share it with advertisers. Its use of Google data follows the Google API Services User Data Policy, including its Limited Use requirements. GitHub hosts these public pages under the GitHub privacy statement.

Contact

For questions about this personal utility, contact the site maintainer on GitHub.
